# Phase 9 — Notes Board & Regional Content Packs

## Goal

Two capabilities that ship together because they're both about *gift-
ability* — the smallest possible change to make a SIGNAL build feel
purpose-built for a given recipient.

**9A — Local notes board.** The one write path worth allowing: a
text-only, ephemeral, owner-moderated message wall. Wipes on reboot.
**9B — Regional content packs.** Pre-curated `--pack=<name>` bundles
(Cascadia / Gulf Coast / Mountain West / Urban Resilience) plus
printable field cards.

## What was built

| Artifact | Path |
|---|---|
| Notes service | `notes/signal_notes/main.py` (FastAPI on `:8400`) |
| Storage | `notes/signal_notes/storage.py` (SQLite over tmpfs) |
| Rate limit | `notes/signal_notes/rate_limit.py` (1/min + 10/hour per IP) |
| Validation | `notes/signal_notes/validation.py` (280 char cap, control-char strip) |
| Tests | `notes/signal_notes/tests/test_notes.py` (post, list, delete, wipe, rate-limit, owner-token) |
| Systemd unit | `systemd/signal-notes.service` (RuntimeDirectory=tmpfs, sandboxed) |
| Owner token | `/etc/signal/notes-owner-token` (32 hex chars, 0600) |
| Board UI | `www/portal/board.html` + `www/portal/assets/js/board.js` |
| Packs | `packs/<name>/pack.yaml` for 5 regional packs |
| Pack schema | `packs/SCHEMA.md` |
| Pack applier | `scripts/apply_pack.sh` (workstation; install.sh wraps for portal) |
| nginx routes | `/api/notes`, `/print/` |
| Installer step | `phase9()` + `--pack=<name>` flag in `install.sh` |
| Uninstaller step | `remove_notes()` in `uninstall.sh` |

## Notes board endpoints (`POST /api/notes`, …)

```
GET    /api/notes?limit=100        → { notes: [...] }
POST   /api/notes  {text, name?}   → 201 { id, created_ts, name, text }
                                   → 429 (1/min or 10/hour per IP)
                                   → 400 (empty after sanitisation)
DELETE /api/notes/{id}             → 204 (X-Owner-Token required)
POST   /api/notes/wipe             → { wiped: N } (X-Owner-Token required)
GET    /api/notes/health  (proxied → /health) → { ready, note_count }
```

### Spec compliance

| Spec | Where |
|---|---|
| Text-only, 280-char limit | `validation.clean_text` |
| Plain-text rendering (URLs not clickable) | `board.js` uses `textContent`, never `innerHTML`, for note bodies |
| 1 post/IP/60s, 10 posts/IP/hour | `rate_limit.check` + Retry-After header |
| Ephemeral — wiped on reboot | tmpfs via systemd `RuntimeDirectory=` |
| Owner moderation | DELETE + wipe gated on `X-Owner-Token` |
| Optional display name | accepted, never an account |
| Optional profanity filter | not enabled by default; hookable in `validation.clean_text` |

## Regional packs

Five packs ship with v0.9:

* `general-purpose` (default)
* `pacific-northwest`
* `gulf-coast`
* `mountain-west`
* `urban-resilience`

Schema (`packs/SCHEMA.md`) covers `zims`, `print[]`, and optional
`noaa.preset_frequencies_mhz` for Phase 8.

### Applying a pack

Workstation:

```bash
./scripts/apply_pack.sh pacific-northwest
rsync -avh payload/var/lib/kiwix/ pi@hub.local:/var/lib/kiwix/
rsync -avh payload/var/www/signal-portal/print/ pi@hub.local:/var/www/signal-portal/print/
```

Pi:

```bash
sudo ./install.sh --pack=pacific-northwest
```

The flag stages the print/ tree only — ZIMs are intentionally a separate
copy because they're huge.

### Printable field cards

`/print/` is an nginx alias onto `/var/www/signal-portal/print/`. The pack
applier writes an `index.html` listing the PDFs by their human title; the
Print tile on the landing page deep-links to it. PDFs themselves are
produced at workstation pack build time — none are bundled in the repo
because pre-rendered PDFs are large and the licensing varies.

## Acceptance

- Post / read / wipe + rate limiting demonstrated by `test_notes.py`.
- Board tile self-disables when `/api/notes` is unreachable.
- Print tile self-disables when `/print/` is absent.
- `install.sh --pack=<name>` lays down the right print tree; ZIMs come
  through the existing workstation `content/fetch.sh` flow.

## Known limitations going into the next phase

- Mesh-propagated notes (Phase 9.2) require Phase 7; the schema already
  records `name` and timestamp but signature + TTL fields are not yet
  emitted. The signal-notes service will gain a `mesh_origin` column
  when Phase 7 lands.
- Printable PDFs are not generated by this repo — packs reference files
  the workstation operator produces (or hands in for a print run). v0.9
  ships the index page only.
- Profanity filtering is hookable but off by default; we want the
  community-experience report from a real deployment before turning it on.
