Blueprint overview

rpi-hub is a self-contained Wi-Fi access point on a Raspberry Pi that serves a curated knowledge library, a retrieval-grounded assistant, an ephemeral notes board, RTL-SDR radio reception, and a Reticulum + BATMAN-adv mesh control plane — without any internet uplink, telemetry, or transmit capability. This page is the operator's blueprint: architecture at a glance, service map, hardware tiers, port inventory, and what's still gated on bench hardware. For prose see docs/OVERVIEW.md; for the build checklist see rpi-hub-wizard.html.

Unreleased polish landing on top of v1.2.1 The pending tree adds opt-in ADS-B position-rounding (rpi-hub-adsb-shield, gated on /etc/rpi-hub/adsb-precision), a split owner-token model (/etc/rpi-hub/{notes,mesh}-owner-token with a non-breaking legacy fallback), an explicit captive-portal HTTPS out-of-scope note in OVERVIEW §4.6, and test harnesses for readonly_root.sh and the cross-service notes → mesh fan-out. Service-down classes are unified as .svc-status / .svc-fallback / .ask-defer across every portal page. See CHANGELOG [Unreleased] for the full set; the headline shipped tag remains v1.2.1 until cut.
